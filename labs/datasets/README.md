# labs/datasets

Reserved for compact, checked-in datasets used by later chapters (e.g.
sample `perf` output, pre-captured flame graph data, latency traces for
Appendix F's statistical-reasoning examples).

Not populated: Chapters 1-30's guided labs generate all of their own data
live via `cyclelab` and the scripts in `labs/scripts/` (or, for
`perf`/PCM-dependent material in Chapters 10, 12, 15, and 20, the
NUMA/affinity material in Chapters 23-25, or the `bpftrace`/BCC material
in Chapters 26-28, all unavailable on this reference machine, are
documented schematically instead of relying on a captured dataset), so
no static dataset is needed.
